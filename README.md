# Vardiya Planı

Küçük mağazalar için hazırlanmış, doğrudan tarayıcıda çalışan sade haftalık vardiya planlama sitesi.

## Özellikler

- Dört personel için haftalık plan oluşturma
- Sabah, Öğlen, Full ve İzin vardiyaları
- Açılış ve kapanışta en az iki personel kontrolü
- Kişi başı yaklaşık 45 saat hedefi
- Haftada bir izin ve izin günü tercihi
- Personel bazında çalışılabilir vardiya seçimi
- Tüm haftayı tek tabloda görüntüleme
- Hücreye tıklayarak manuel vardiya değiştirme
- Verileri yalnızca tarayıcıda saklama

## Kullanım

`index.html` dosyasını tarayıcıda açmak yeterlidir. Sunucu, kurulum veya paket yöneticisi gerekmez.

GitHub Pages adresi:

`https://cesase.github.io/vardiya-plani/`
